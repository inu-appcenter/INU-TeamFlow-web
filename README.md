# 모이미 (Moimi)

> 대학생 팀 프로젝트와 스터디를 위한 올인원 협업 플랫폼

## 📖 서비스 소개

모이미는 교내 팀 프로젝트, 스터디, 공모전, 동아리 등 다양한 협업 활동을 위한 플랫폼입니다.

기존에는 팀 모집, 교내 정보 탐색, 일정 관리와 조율을 여러 서비스에서 각각 진행해야 했습니다. 모이미는 이러한 과정을 하나의 서비스로 통합하여 팀 구성부터 운영까지 효율적으로 관리할 수 있도록 지원합니다.

## 🎯 서비스 목표

- 🤝 팀 모집과 팀 운영을 하나의 서비스에서 제공

- 📅 개인 일정과 팀 일정을 함께 관리하는 통합 캘린더

- 🗳️ 일정 투표를 통한 팀원 간 일정 조율

- 💬 팀 단위·개인·그룹 실시간 채팅으로 바로 소통

- 📢 교내 정보 탐색부터 모집까지 자연스럽게 연결

## ✨ 주요 기능

| 기능        | 설명                                             |
| ----------- | ------------------------------------------------ |
| 팀          | 팀 생성·관리, 팀원 초대, 팀 공지                 |
| 모집        | 모집글 작성, 지원, 지원서 확인                   |
| 캘린더      | 개인/팀 일정 통합 관리, 반복 일정                |
| 투표        | 일정 조율을 위한 팀 투표                         |
| 채팅        | 1:1·그룹·팀 채팅방, 읽음 처리, 이미지 전송       |
| 정보 게시판 | 교내 정보 탐색, 스크랩                           |
| 알림        | FCM 푸시 알림, 알림 설정                         |
| 마이페이지  | 내 게시글, 스크랩, 초대, 투표, 문의, 재학생 인증 |
| 신고·문의   | 신고 접수 및 1:1 문의                            |
| 관리자      | 대시보드, 문의·신고 관리                         |
